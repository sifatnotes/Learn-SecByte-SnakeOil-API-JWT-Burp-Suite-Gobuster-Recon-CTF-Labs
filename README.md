# Learn SecByte SnakeOil API, JWT, Burp Suite, Gobuster & Recon CTF Labs

Hands-on cybersecurity and CTF lab collection focused on SnakeOil APIs, JWT authentication, token handling, Burp Suite, HTTP methods, API discovery, Gobuster, web fingerprinting, and port-based reconnaissance.

These labs are useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners practicing authorized web-security testing.

## Introduction

This collection covers practical web application and API security workflows, beginning with reconnaissance and progressing into authentication, JWT, HTTP request manipulation, API enumeration, and hidden-path discovery.

The labs provide focused practice with access and refresh tokens, API registration, Burp Suite interception and request replay, HTTP method mismatches, web fingerprinting, and service discovery on common web ports.

Use these exercises only against intentionally vulnerable or explicitly authorized systems.

## Learning Path

A practical progression is:

1. Start with **SnakeOil on Port 80** and **8080 Snake Oil Lab** to understand web-service discovery.
2. Use **SnakeOil Fingerprint** to practice identifying web application characteristics.
3. Continue with **Gobuster: Map the Hidden Paths** for web-path enumeration.
4. Explore **SnakeOil API Hunt** and **Snake-Oil APIs** for API discovery.
5. Study **Method Mismatch Snake Oil API** to understand HTTP method handling.
6. Practice request analysis with **Burp Intercept Snake Oil**.
7. Continue with **Burp Repeater Snake Oil Lab** for controlled request modification and replay.
8. Study **JWT SnakeOil** and **SnakeOil API JWT Registration** for JWT-based API authentication.
9. Finish with **Token Swap: Access vs Refresh** to examine access and refresh token concepts.

## How to Use the Labs

1. Select a lab from the direct-link index.
2. Confirm that the target is an authorized training environment.
3. Read the objectives and understand the permitted scope.
4. Begin with reconnaissance before deeper testing.
5. Document hosts, ports, endpoints, HTTP methods, headers, tokens, and application behavior.
6. Use Burp Suite or Gobuster only against permitted lab targets.
7. Record your testing methodology and findings.
8. Review secure API and authentication practices after completing each exercise.
